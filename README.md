## How It Works

1. 📝 **Submit** — Open an issue using our template
2. 🎨 **Review** — Our AI designs a solution and posts it for your approval
3. 💻 **Build** — Once approved, AI developers implement the project
4. 🔍 **Quality** — Automated code review and testing
5. 🚀 **Deliver** — Get your project as a GitHub Release

## Quick Start

1. Click **New Issue**
2. Fill out the feature request template
3. Wait for the design review (usually within 30 minutes)
4. Approve the design or request changes
5. Receive your completed project!

## Status Labels

| Label | Meaning |
|---|---|
| `new-request` | Just submitted, in queue |
| `designing` | AI is creating a technical design |
| `awaiting-feedback` | Design ready — your review needed! |
| `in-progress` | Development underway |
| `in-review` | Code review in progress |
| `testing` | Running automated tests |
| `releasing` | Packaging for release |
| `completed` | Done! Check the Release link |
| `stale` | No response for 72h, auto-closed |
| `needs-help` | Requires manual intervention |
